UI redesign · companion

The pipeline
is a colormap.

napariTFM turns bead displacement into traction and cell stress — one ordered sequence on one grid. The redesign makes the dock read as that sequence: a viridis spine you watch fill in as the analysis completes.

01

A gradient spine, not five flat cards

Stages sample the viridis ramp start→end and connect down the left gutter. A finished run lights the spine top-to-bottom; each node encodes status at a glance — restoring the signal the old status dot lost.

02

Status lives in the node

Done fills + glows in the stage's accent. Running pulses amber. Ready is a hollow accent ring. Idle is a dim dot. Semantics never fight the accent because they read as fill-state, not hue.

03

Physical values in monospace

Every readout — 12.0 µm, 9.00 kPa, 10⁻⁶ — sets in IBM Plex Mono with the unit dimmed. A lab-instrument register, and numbers align in the two-up grid.

04

Drawn icons replace the emoji

🔍⚙▷▶ rendered differently on every OS. Crisp stroked glyphs — files, params, preview, run/stop — tinted from the stage accent read as one designed set.
